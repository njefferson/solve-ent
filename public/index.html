Before you start

Practice for the algebra a chemistry calculation needs — rearranging a formula, using a ratio, moving powers of ten, cancelling units, keeping the right number of figures. Seven kinds of move, and nothing else.

It does not solve the question. When an answer is wrong it works out which mistake produces that exact number and tells you — and when it cannot tell, it says so instead of guessing.

Nothing you type is sent anywhere. There is no account and nothing stored about you.

What do you want to work on?

Pick one. Five questions, one step at a time. Nothing is recorded and nothing is scored.

    Or do a set somebody has given you

    If you were given a key and a number, this is where they go. At the end you get a code to hand back, and that code is the only thing that leaves the device.

    Or practise one move on its own

    If one particular step is the one going wrong, doing whole questions makes you walk past it four times to reach it once.

    There is a set here that was not finished

    Carrying on picks it up at the step it stopped on, with everything already done still counted. Starting something else forgets it, and there is no way back to it after that.

              What it is, and what it is not
              
  
              Free tools already solve these and already show the steps. What this adds is looking at a wrong answer and working out which mistake produces that exact number — the ratio used upside down, the exponent multiplied instead of raised, a conversion factor turned the wrong way — and telling you that.
              
  
              It refuses to guess. When two different mistakes would produce answers nobody could tell apart, it will not ask that question at all. When it cannot work out what happened, it says so rather than picking something that sounds likely.
              
  
              There is a calculator in the bar at the top, on every screen, because you should not need a second thing in front of you to work out a number. Choosing what to multiply, and which way up to put it, is the whole of what this is for, and it never does that part.
              
  
              The name is a pun: solve, and solvent. That is the only time it will be mentioned.

              Where the questions come from
              
  
              They are worked out on this device, from a starting key, using constants taken from published reference values — the Avogadro constant, molar volumes, standard unit conversions. Nothing is downloaded and nothing is looked up while you work. The same key produces the same questions on every device, which is what lets a group work from one thing written on a board.
              

  
              What it stores
              
  
              Your settings, and which version you last saw this panel for. That is all, and it stays on this device. There is no account, no sign-in, no cookie and no analytics. If work is ever set with a number attached to it, that number is a number somebody assigned — never a name, and never anything that says who you are.
              

  
              Something is wrong with it
              
  
  
              The flag in the bar at the top opens a report you can copy and send on. It says which version and which kind of device, which is usually the whole answer.
