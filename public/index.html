Before you start

This is practice for the algebra a chemistry calculation needs — rearranging a formula, using a ratio, moving powers of ten, cancelling units, and keeping the right number of figures. Seven kinds of move, and nothing else.

It is not a calculator and it is not a solver. Free tools already work these out and already show the steps. What this does instead is look at a wrong answer and work out which mistake produces that exact number — the ratio used upside down, the exponent multiplied instead of raised, a conversion factor turned the wrong way — and tell you that.

And it refuses to guess. When two different mistakes would produce answers nobody could tell apart, it will not ask that question at all. When it cannot work out what happened, it says so rather than picking something that sounds likely.

Nothing you type is sent anywhere. There is no account, no sign-in and nothing stored about you.

The name is a pun: solve, and solvent. That is the only time it will be mentioned.

What do you want to work on?

Pick one. Five questions, one step at a time. Nothing is recorded and nothing is scored.

    Or practise one move on its own

    If one particular step is the one going wrong, doing whole questions makes you walk past it four times to reach it once.

            Where the questions come from

            They are worked out on this device, from a starting key, using constants taken from published reference values — the Avogadro constant, molar volumes, standard unit conversions. Nothing is downloaded and nothing is looked up while you work. The same key produces the same questions on every device, which is what lets a group work from one thing written on a board.

            What it stores

            Your settings, and which version you last saw this panel for. That is all, and it stays on this device. There is no account, no sign-in, no cookie and no analytics. If work is ever set with a number attached to it, that number is a number somebody assigned — never a name, and never anything that says who you are.
