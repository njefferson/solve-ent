      What a code can and cannot tell you

      It carries the number the student was given, how many steps they attempted, how many they got right first time, how many went wrong in each kind of move, and roughly how long it took. That is everything in it.

      It carries nothing about who they are beyond that number — no name, no device, nothing they typed. It also carries nothing about the accommodations they were using, and there is nowhere in it for that to go: text size, spacing, one step at a time and read-aloud stay on the device, so nobody has to disclose a thing by handing a code back.

      The check is a typo detector, not a signature. It catches a character copied wrong, a code from a different set, a different topic, or an easier difficulty than the one you set — which is what actually goes wrong in a room. It cannot stop somebody who reads the source of this page and writes their own: there is no server here, so there is no secret to keep one out. It would be easy to imply otherwise and it would not be true.
